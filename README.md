# Cobra Kai Google Slides

This repository contains a Google Apps Script that creates a 12-slide Cobra Kai presentation.

## Create the presentation

1. Open [script.google.com](https://script.google.com/).
2. Create a new Apps Script project.
3. Copy the contents of `cobra-kai-slides.gs` into the editor.
4. Run `createCobraKaiPresentation`.
5. Approve the Google permissions when asked.
6. Open the presentation URL shown in the execution log.

## Release
